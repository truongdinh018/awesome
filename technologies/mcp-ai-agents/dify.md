## Đây là gì?

dify là xây workflow agentic & RAG (tự động hóa, LLM, low-code).

Theo GitHub: Build Agentic workflows, RAG pipelines, with rich AI model and tool support on one collaborative workspace. Deploy on cloud, VPC, or self-hosted, so teams move from prototype to production without rebuilding the stack.

Điểm nổi bật tuần này: Code mới push hôm nay.
