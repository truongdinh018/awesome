## Đây là gì?

open-design là bản mở thay thế Claude Design (agent AI, AI sinh tạo, no-code).

Theo GitHub: 🎨 The open-source Claude Design alternative. 🖥️ Local-first desktop app. 🖼️ Your coding agent becomes the design engine: prototypes, landing pages, dashboards, slides, images & video — real files, HTML/PDF/PPTX/MP4 export. 🤖 Claude Code / Codex / Cursor / Gemini / OpenCode / Qwen & 20+ CLIs via BYOK.

Điểm nổi bật tuần này: Code mới push hôm nay.
