## Đây là gì?

litellm là dự án LLM / AI sinh tạo (LLM) — The nhanh nhất litest AI Gateway Rust core with Python SDK Call LLM APIs OpenAI tích hợp sẵn.

Theo GitHub: The fastest, litest AI Gateway. Rust core with Python SDK. Call 100+ LLM APIs in OpenAI (or native) format with cost tracking, guardrails, load balancing, and logging [Bedrock, Azure, OpenAI, Anthropic, OpenAI, VertexAI, vLLM, Nvidia NIM]
